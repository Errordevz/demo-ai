GET STARTED

Run it locally.

unzip demo-ai-100m-portable.zip
cd demo-ai-100m-portable
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python smoke_test.py
python run_local.py --prompt "Write a Python function that reverses a linked list."

The current checkpoint is a development model. It is portable and runnable, but it is not yet a frontier-grade or professionally trained model.
